# 室内通风模拟器 (Indoor Ventilation Simulator)

基于 **D2Q9 格子玻尔兹曼方法（LBM）** 的浏览器端自然通风模拟工具。单文件实现，零依赖，双击 `index.html` 即可运行。

覆盖两个尺度：**小区室外风环境**（多高度切片 2D 模拟）与 **户型室内通风**（MRT-LBM），室外结果可作为室内建模的逐窗来流边界。

## 功能特性

### 户型室内通风
- **MRT-LBM 求解器** — 多松弛时间碰撞（9 个独立松弛率，解析逆变换），pull 流动、full-way bounce-back 墙体反弹，144×100 网格（0.1m/格，面积校准后可变）
- **户型图导入与自动识别** — 上传户型图（PNG/JPG/SVG），基于中值亮度采样自动识别墙体轮廓；支持底图叠加、透明度调节、指北针方向设置
- **笔刷建模** — 墙 / 窗 / 门 / 家具 / 橡皮擦自由编辑，支持直线模式；撤销/重做（50 步）
- **两类家具** — 通顶柜体（固壁全反射）与矮家具（Darcy 阻力渗流，风可穿过但减速）
- **进风面分析** — 根据风向（16 方位）自动识别窗户进风面并可视化
- **逐窗风场覆盖** — 可对每扇窗单独指定进/排风方向与风速（默认取盛行风）；有小区建模时可一键采用小区提取的户外风
- **风扇模拟** — 任意位置放置自定义风量风扇（m³/h 标定），评估机械通风方案
- **热力图可视化** — 风速热力图（预合成发光层）+ 粒子流 + 矢量场 + 窗口实时进/排风量标注
- **通风指标量化** — 换气次数 ACH、逐房间 t50/t90 排空时间、示踪剂（CO₂ 替代物）浓度曲线、风量平衡 Qin/Qout
- **多方案对比** — 并行运行多个开窗/风扇方案，生成对比报告（可导出打印）

### 小区室外风环境
- **平面图楼栋识别** — 上传小区平面图，自动识别楼栋轮廓（Moore 边界追踪转多边形）；支持深/浅色极性切换
- **多边形楼栋建模** — 顶点绘制（Esc 取消 / 右键撤销顶点）、楼栋复制（同小区相似楼栋快速复用）、逐楼栋层数设置（3m/层换算总高）
- **可调指北针** — 校正上传平面图的朝向偏差
- **多高度切片模拟** — 最多 6 个高度切片，只有不低于切片高度的楼栋参与遮蔽，近似三维绕流效应
- **户型位置标记** — 在小区图上标记待建模户型的位置与楼层，提取该处各风向下的局部风速风向，供室内建模使用
- **城市风数据库** — 内置多城市冬/夏季盛行风向风速

### 数据与工程
- **本地持久化** — localStorage 自动保存（30 秒节流，仅在有改动时写入）；支持方案导出/导入 JSON
- **回归测试** — `_test/harness.js` 无头加载应用脚本，跑完整模拟并断言 7 项指标（质量守恒、ACH 范围、密度有界等），失败时非零退出

## 使用方法

直接用浏览器打开 `index.html`：

1. （可选）小区建模：上传小区平面图 → 自动识别或手绘楼栋多边形 → 设置各楼栋层数与指北针 → 标记户型位置 → 运行切片模拟
2. 上传户型图，设置比例尺，用笔刷修正墙体、门窗、家具
3. 设置室外风向风速（或采用小区提取结果 / 放置风扇）
4. 运行模拟，查看热力图与通风指标
5. 对比多方案，导出通风建议报告

## 项目结构

```
index.html          # 全部应用（UI + LBM 引擎 + 可视化，约 3300 行 vanilla JS）
_test/harness.js    # Node 无头回归测试（守恒律与指标断言）
_test/mrt_rebuild_check.js  # MRT 解析逆变换正确性校验
docs/               # 设计文档（室外风环境优化方案等）
```

## 物理模型说明

- 不可压低速流近似；室内 MRT 碰撞（στ=0.56，家具格 τ=2.5），室外 BGK
- 窗户边界：进风面速度边界（Zou/He 型），出风面零梯度
- 小区模拟：2D 多高度切片 + 高度遮蔽，非真正三维求解，精度介于纯 2D 与 3D 之间
- 示踪剂输运：对流-扩散混合格式，仅气相单元混合
- 已知特性：室内存在约 4~6% 过密度（LBM 压力边界导致），ACH 与 t90 指标仍自洽
