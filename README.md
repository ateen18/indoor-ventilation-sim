# 室内通风模拟器 (Indoor Ventilation Simulator)

基于 **D2Q9 格子玻尔兹曼方法（LBM）** 的浏览器端室内自然通风模拟工具。单文件实现，零依赖，双击 `index.html` 即可运行。

## 功能特性

- **LBM 流体求解器** — BGK 碰撞（τ=0.56）、pull 流动、full-way bounce-back 墙体反弹，144×100 网格（14.4m × 10m）
- **户型图导入与自动识别** — 上传户型图（PNG/JPG/SVG），自动识别墙体轮廓并生成网格模型；支持底图叠加、透明度调节、指北针方向设置
- **笔刷建模** — 墙 / 窗 / 门 / 家具 / 橡皮擦自由编辑，支持直线模式；橡皮擦区域与底图像素级一致
- **进风面分析** — 根据风向（支持 16 方位）自动识别窗户进风面并可视化
- **风扇模拟** — 任意位置放置自定义风量风扇（m³/h 标定），评估机械通风方案
- **热力图可视化** — 风速大小、空气年龄、示踪剂浓度（CO₂ 替代物）多模式渲染
- **通风指标量化** — 换气次数 ACH、平均室内风速、污染物 90% 排空时间 t90、逐房间风量平衡（Qin/Qout）
- **多方案对比** — 并行运行多个通风方案，对比生成最优通风摆放建议报告

## 使用方法

直接用浏览器打开 `index.html`：

1. 上传户型图，设置比例尺（或自动识别）
2. 用笔刷修正墙体、门窗、家具
3. 设置室外风向风速（或放置风扇）
4. 运行模拟，查看热力图与通风指标
5. 对比多方案，导出通风建议报告

## 物理模型说明

- 不可压低速流近似，单松弛时间 BGK 碰撞
- 窗户边界：进风面施加速度边界条件（Zou/He 型），出风面零梯度
- 示踪剂输运：对流-扩散混合格式，仅气相单元混合
- 已知特性：室内存在约 6% 过密度（LBM 压力边界导致），ACH 与 t90 指标仍自洽
